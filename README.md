# Finanzas

App para apuntar ingresos y gastos desde el iPhone. Funciona sin conexión y guarda los datos en el propio móvil.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `finanzas`) y sube todos los archivos de esta carpeta a la raíz.
2. Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
3. Al cabo de un minuto estará en `https://TU-USUARIO.github.io/finanzas/`.

## Instalar en el iPhone
Abre la URL en Safari → Compartir → "Añadir a pantalla de inicio".

## Actualizar
Sube los cambios y sube también la versión en `sw.js` (por ejemplo `finanzas-v2` → `finanzas-v3`).

## Copias de seguridad
Ajustes → "Exportar copia de seguridad" genera un `.json` que puedes guardar en Archivos o iCloud. Para restaurar, "Importar copia de seguridad".
